아래와 같은 조건의 프로그램을 만들어 줘.

환경: Visual Studio 2022 프로젝트 + C# + .NET 9.0 + Windows Forms

UI 외관: 상단에 메뉴 및 툴바
             왼쪽 패널에 트리
             오른쪽 패널에 메일 목록을 볼 수 있는 뷰
            

기능: 신규 메일 계정 등록 (지원: 아웃룩, GMail 등을 POP3 또는 IMAP으로 통신 가능)
        등록된 메일 계정에 따라 왼쪽 트리에 Inbox / Sent Items / Junk Email / Deleted Items 하위 노드를 갖는 트리 노드 생성
        각 노드 간에 메일 이동 가능, 예를 들어 Inbox에 있는 메일 항목을 드래그해서 Deleted Items로 전달 가능, 메뉴로도 다른 노드로 전달 가능
        주기에 따라 신규 메일을 확인 (기본 주기 5분: 설정 가능)
        
        메일 쓰기, 메일 읽기, 메일 reply, 메일 forward 가능

        Junk Email 판단 기능 추가, 설정을 통해 특정 이메일 주소나 도메인 주소에서 오는 메일은 예외로 처리 가능
